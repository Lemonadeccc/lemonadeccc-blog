## 9) Code Block (TypeScript)

```ts
import { gsap } from "gsap";

const tl = gsap.timeline({ defaults: { duration: 0.45, ease: "power2.out" } });

tl.addLabel("enter")
  .from(".card-title", { y: 30, autoAlpha: 0 }, "enter")
  .from(".card-meta", { y: 20, autoAlpha: 0 }, "enter+=0.08");
```
