# Translation Style (EN -> ZH)

## Goals

1. 保持原文语义准确。
2. 保持技术文本简洁、可读。
3. 保持 MDX 结构可渲染且不破坏语法。

## Terminology

1. 技术名词优先采用常见中文译法，不强行生硬直译。
2. 库名与 API 名保持原样：`React`, `Next.js`, `GSAP`, `Node.js`, `pnpm`。
3. 命令、参数、路径、URL 保持原样。

## Frontmatter Rules

1. 将 `title`, `type`, `project`, `summary` 翻译成自然中文。
2. 保留键名，`date` 不改动。
3. 可选 `image` 路径不改动。

## Markdown / MDX Rules

1. 仅翻译叙述性文本。
2. 不改动代码块、内联代码、链接地址、媒体路径、HTML/JSX 结构。
3. 标题层级保持一致。

## Tone

1. 语气直接、实用。
2. 不写营销化夸张表达。
3. 句子长度适中，优先技术可读性。
